# 새 정책 미디어로 넓히기

중랑정책미디어(2026-10~11 창간)를 첫 선례로 삼아, 다른 주제·부서·기관에 같은 방식을 세울 때의 순서. 각 단계의 판단은 그 매체의 발행인이 한다.

## 1. 목적과 독자

- 누구의 어떤 결정에 기여하나(예: 구청장 공약 이행, 특정 국·과의 사업 설계, 의회 보고).
- 독자는 누구이고 하루에 몇 분을 쓰나. 중랑은 직원·간부, 3분 읽기.
- 감시·평가 매체가 아님을 첫 문장에 박는다(정체성 문장 + 모토).

## 2. 헌장

- 머리는 밖에서, 외부 : 내부 비율, 해외 : 국내 균형, 글 순서(촉 → 읽기 → 침 → Q), 분량.
- 평가로 느껴지지 않는 문체(references/style-and-selection.md A를 그대로 가져가 독자에 맞게 예시만 바꾼다).
- 촉 고르기 기준: 그 조직의 공약·계획·핵심 과제 목록을 '연결 지도'로 만들고 신호마다 꼬리표를 단다(중랑은 민선9기 7대 비전).
- 침은 의견이며 결정이 아니라는 문장.

## 3. 엔진 배치 (한 자리 한 엔진)

- 집필 1곳(Claude 예약 작업), 촉 레이더·검증 1곳(GPT 프로젝트 대화), 기획·진열·점검 1곳(Aside routine).
- 같은 자리에 두 엔진이 따로 쓰지 않는다. 판단이 갈리면 '두 시선' 상자.
- 두 엔진이 같은 근거를 보도록 '고정 참조 한 곳' 파일을 처음부터 만든다.

## 4. 저장소·사이트

- 규칙 원장 저장소(헌장, 연결 지도, 실험표, 참조 허브, 후보 inbox).
- 진열 사이트(정적 + Vercel). 원본 피드가 늦어도 되도록 `data/editions.json` 같은 직송 피드를 처음부터 둔다.
- 쓰기 권한 경로를 먼저 정한다: Claude 예약 작업은 '자동' 권한에서 공개 저장소 push가 막힌다. Aside 웹 업로드(PC 상시 가동) 또는 별도 경로를 발행인과 정한다.

## 5. 일정

- 후보 수확(전날 업무 시간) → 집필(새벽) → 진열·점검(출근 전) → 후속(오전). "먼저 발행, 후속은 나중".
- 휴간 요일, 호수 체계, 정정판 규칙.

## 6. 예비호(파일럿)

- 1~2주, 평일. 하루 한 가지 실험(references/experiments.md 설계 규칙).
- 매일 점검 메일 + 누적표, 1주차 중간 평가, 창간호 구성안, 가부 판단 자료.

## 7. 창간 가부

- 기준(머리 외부 비율, 평가 표현 0, 균형, 연결 꼬리표, 후보 채택, 진열 시각, 분량)을 미리 적어 두고 발행인이 결정한다.
