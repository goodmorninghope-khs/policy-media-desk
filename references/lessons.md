## 도구 요령

- Claude 예약 작업 편집: 작업 페이지 '더 많은 옵션' → '편집' 대화상자. 지침이 길면 snapshot이 16KB에서 잘리므로 `[role="dialog"] textarea` 중 값이 긴 것을 직접 fill. 시간은 '시간' 입력. 저장 후 새로고침해 '다음 실행'과 지침 첫 줄로 확인.
- Claude 실행 기록: 작업 페이지 '오늘 오전 H:MM' 링크 → chat 페이지 main innerText. 지면 PNG는 img src `.../files/{id}/preview`(webp, 896px)만 받아진다(contents·download는 404).
- 새 예약 작업: '새 작업' → '직접 설정'.
- GitHub 웹 업로드: `upload/main/{폴더}`에서 input[type=file], 1~2개씩. 바로 이어 올리면 "Commit failed"가 날 수 있다 → 업로드 페이지를 다시 열어 재시도. 커밋이 되면 주소가 '/upload'(슬래시 없음)나 저장소 루트로 바뀐다. 반영은 commits 페이지로 확인하고, raw.githubusercontent.com main 주소는 몇 분~더 오래 옛 내용을 줄 수 있어 내용 대조는 커밋 sha 주소나 github.com/…/raw/main/… 로 한다. 없는 하위 폴더 업로드 경로는 피한다.
- ChatGPT 대화 입력: 보이는 div.ProseMirror(nth(1)) 클릭 → keyboard.insertText → `button[aria-label="보내기"]`. 보내기 click이 disabled로 실패하면(11/3) 입력창에 focus를 두고 Enter, 그래도 안 되면 새로고침(초안 복원) 뒤 버튼이 풀릴 때까지 1초 간격으로 보고 Enter. 답은 /api/auth/session accessToken으로 /backend-api/conversation/{id} mapping에서 마지막 assistant(status finished_successfully). U+E000~U+F8FF 문자와 'genui{…}}' 표식을 지운다. GPT 답에 일본어가 섞여 나올 때가 있다(11/4) → 한국어로 옮겨 적는다.
