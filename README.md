# policy-media-desk · 정책 미디어 데스크

> 밖에서의 촉이, 안의 결정을 건강하게 하는 침으로.

미디어 방식으로 **내부 정책 결정에 기여하는** '정책 미디어'를 세 AI가 나눠 운영하는 스킬이다. 감시하는 신문이 아니라, 해외·국내 정부 원문·연구·다른 도시의 실행 사례를 읽어 내부 의사결정자가 부담 없이 "우리라면?"을 생각해 보게 하는 매체를 만든다.

첫 선례는 서울 중랑구 정책실의 **중랑정책미디어**(JUNGNANG SIGNAL × 아궁이, https://jungnang-media.vercel.app , 창간 2026-11-11)다. 이 저장소는 그 창간 과정(예비호 파일럿, 일정 개편, 문체·공약 연결 기준, 하루 한 가지 실험)에서 쌓인 노하우를 다른 주제·부서·기관으로 옮길 수 있게 정리한 것이다.

| 누구 | 역할 |
|-|-|
| Claude 편집국 | 지면 집필·발행(새벽 예약 작업) |
| GPT 외부고문 | 촉 레이더 후보(전날), 사후 사실 확인 |
| Aside 기획단장 | 일정·진열·점검·실험·보고·노하우 축적, 다른 스킬과의 연계 |
| 발행인 | 창간·기준·가부 등 주요 판단 |

## 구성

| 경로 | 내용 |
|-|-|
| `SKILL.md` | 정체성, 세 엔진 역할, 하루 루프, 편집 기준 요지, 실험 운영, 밸류체인, 확장, 판단 경계 |
| `references/style-and-selection.md` | 읽는 사람이 평가받는다고 느끼지 않는 문체(쓰지 않는 말·바꿔 쓰기 예), 공약·주요 사항에 닿는 촉 고르기와 '닿는 공약' 꼬리표 |
| `references/experiments.md` | 하루 한 가지 실험 설계 규칙, 예비호 실험 E1~E7과 결과 |
| `references/value-chain.md` | 원료 → 제작 → 진열 → 정책화 → 확산·학습 → 기록 → 되먹임, 고리별 연계 스킬 |
| `references/expansion-playbook.md` | 새 정책 미디어를 세우는 8단계 |
| `references/lessons.md` | 운영 노하우(결정·권한·환경·도구 요령), 매주 갱신 |
| `references/jungnang-instance.md` | 중랑 사례의 일정·호수·주소·가부 기준(내부 ID 제외) |

## 원칙

- 침(제안)은 편집국 의견이며 행정 결정이 아니다. 결정은 각 고리의 책임자가 한다.
- 실제 내부 의제·주민 정보·비공개 원문·작업 ID는 이 저장소에 넣지 않는다.
- 중랑구의 공식 조직·지침을 선언하는 저장소가 아니다.
